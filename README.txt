SITE — LAURA SOUSA LISBOA | NUTRICIONISTA

COMO ABRIR NO VS CODE
1. Extraia o arquivo ZIP para uma pasta do computador.
2. Abra o Visual Studio Code.
3. Clique em File > Open Folder (Arquivo > Abrir Pasta).
4. Selecione a pasta "site_laura_nutricionista".
5. Abra o arquivo index.html.
6. Para visualizar, clique com o botão direito no index.html e escolha "Open with Live Server".
   Se não tiver a extensão, instale "Live Server" na aba Extensions do VS Code.
   Também é possível abrir o index.html diretamente no navegador.

ESTRUTURA
